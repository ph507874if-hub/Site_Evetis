QUEM SOMOS

Um lugar para encontrar o que faz sentido para você

O Encontraê é uma plataforma para descobrir eventos, conhecer pessoas e tirar ideias do papel. Reunimos experiências de diferentes interesses para que seja mais fácil encontrar algo novo para fazer — ou alguém para fazer junto.
